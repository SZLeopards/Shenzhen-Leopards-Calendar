# 深圳马可波罗 2026–2027 赛程日历

本目录提供深圳马可波罗 2026–2027 CBA 常规赛的订阅日历与移动端添加页面。

- `shenzhen-2026-27.ics`：46 场常规赛，主客场各 23 场，使用 `Asia/Shanghai` 时区；每场默认提前 30 分钟提醒。23 场深圳主场均标明场馆，客场场馆暂时留空。
- `index.html`：通过 `webcal://` 唤起系统日历订阅，并提供 ICS 直接下载作为回退方案。

赛程数据核对口径：CBA 官方数据站的逐日赛程记录；深圳 23 个主场的日期、对手及场馆另与《深圳新世纪烈豹门票推广方案：CBA 26-27 赛季常规赛 V2.1》交叉核对。

注意：官方赛程记录将深圳主场对浙江稠州标为常规赛第 10 轮，但实际开赛时间为 2027 年 4 月 5 日。日历按实际开赛时间展示，并保留官方轮次编号。
